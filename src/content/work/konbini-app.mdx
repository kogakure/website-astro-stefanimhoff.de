  - A shopping app that learns from my own trips instead of asking me to maintain a list. Konbini sorts each list in the order I walk a store, suggests what is running out with the amount I usually take, and works with one thumb, even offline.
  - I designed and built it with SvelteKit and SQLite. It is installable as an app, syncs live within a household, speaks English, German, and Japanese, and has an API and an MCP server for AI agents.
